# Object Lab — การเขียนโปรแกรมเชิงวัตถุ

เว็บบทเรียนภาษาไทยสำหรับ 07-034-206 ภาคปลาย 2569 ชั้นปี 2 ใช้ JavaScript ES6, Node.js/Express, React Function Components และ AI อย่างมีวิจารณญาณ

## เปิดในเครื่อง
ต้องมี Node.js จากนั้นเปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```sh
npm start
```

เปิด http://127.0.0.1:4173 หยุดเซิร์ฟเวอร์ด้วย Ctrl+C ไม่มี package ที่ต้องติดตั้งเพิ่ม

## โครงสร้าง
- `dist/index.html` โครงหน้าและเมนู
- `dist/styles.css` การจัดหน้า responsive
- `dist/lessons.js` เนื้อหา 17 สัปดาห์ แก้ไขบทเรียนและแบบทดสอบที่นี่
- `dist/app.js` การแสดงผล ค้นหา แบบทดสอบ ความคืบหน้า และบันทึก AI
- `starter/` ชุดตัวอย่าง JavaScript ES6 ระบบยืม–คืนอุปกรณ์ พร้อมชุดทดสอบ
- `server.mjs` เซิร์ฟเวอร์พรีวิวเฉพาะเครื่อง

## ขอบเขตการใช้งาน
บทเรียนฉบับเริ่มต้นมีแนวคิด ตัวอย่าง กิจกรรม และคำถามทบทวนหนึ่งข้อต่อสัปดาห์สอน รวม 15 ข้อ สัปดาห์ 8 และ 17 เป็นข้อมูลสอบ ไม่มีข้อสอบจริง การเรียนแล้วเป็นการทำเครื่องหมายเอง ไม่ใช่การรับรองผลสัมฤทธิ์

ไม่มีระบบสมาชิก ฐานข้อมูล การส่งงาน การเก็บคะแนนจริง หรือ AI API เว็บใช้ตัวอย่าง JavaScript ES6 และสถาปัตยกรรม React → Express Route → Service → Repository เพื่อการศึกษา แต่ไม่ได้เปิด Backend ค้างบนเซิร์ฟเวอร์ ชุด `starter/` รันและทดสอบในเครื่องด้วย Node.js ส่วนการกดคัดลอก prompt ไม่ส่งข้อมูลไป AI

ผู้เรียนผ่านวิชาหลักการเขียนโปรแกรมที่ใช้ Python เบื้องต้นแล้ว รายวิชานี้เชื่อมแนวคิด `class`/object เข้ากับ JavaScript ES6 ที่ผู้เรียนใช้ต่อใน React และ React Native ก่อนเน้นการออกแบบกฎธุรกิจ การทดสอบ และ API

บันทึกความคืบหน้าและ AI log ด้วย localStorage เฉพาะ browser+origin เดิม เปลี่ยนพอร์ต/โดเมน/เครื่องจะไม่ย้ายข้อมูลตาม ต้องส่งออกบันทึกไว้เอง ห้ามบันทึกข้อมูลลับ คำตอบแบบทดสอบอยู่ใน source เพราะใช้ฝึกทบทวนเท่านั้น

## Deploy ภายหลัง
เว็บเป็น static HTML/CSS/JS ไม่ต้อง build อัปโหลดเนื้อหาภายใน `dist/` ไปยังพื้นที่เว็บไซต์ที่ผู้ใช้จัดเตรียม รองรับเส้นทางย่อยเพราะใช้ relative assets และ hash routing ไม่มี server secrets และไม่ต้องติดตั้ง Node บน static hosting

เว็บไซต์เผยแพร่ที่ `https://fms.pnu.ac.th/oop-learning-webapp/` โดยอัปโหลดเฉพาะไฟล์ใน `dist/` ไม่อัปโหลด `node_modules`, `.env`, credential หรือฐานข้อมูล

## Interactive teaching slides
เปิด `slides.html` จากเมนู “สไลด์ทีละขั้น 10 บท · 88 หน้า” บทที่ 1 มี 34 หน้าเพื่อวางพื้นฐาน JavaScript และแนวคิด OOP อย่างละเอียด ส่วนบทอื่นเรียงจากเป้าหมาย แนวคิด อ่านโค้ด ฝึกตาม ตรวจความเข้าใจ และ Jigsaw checkpoint จนประกอบเป็น mini project

- ซอร์ส: `dist/slides.html`, `slides.css`, `slides-stepwise.css`, `slides-fullscreen.css`, `slides-professional.css`, `slides-data.js`, `slides-3d.js`, `slides.js`
- ระบบตัวอักษรใช้ **IBM Plex Sans Thai** สำหรับเนื้อหาภาษาไทยและ **IBM Plex Mono** สำหรับโค้ด พร้อมฟอนต์สำรองเมื่อเครือข่ายไม่สามารถโหลด Google Fonts ได้
- ธีมสไลด์ใช้ลำดับชั้นตัวอักษร พื้นที่ว่าง ความยาวบรรทัด และสีเน้นอย่างจำกัด เพื่อให้อ่านชัดทั้งบนจอคอมพิวเตอร์และโปรเจกเตอร์
- ใช้ JavaScript/CSS/WebGL แบบไม่พึ่ง CDN หรือ package ภายนอก เพื่อคงการ deploy แบบ static
- ควบคุมด้วยปุ่มหรือ ←/→, PageUp/PageDown, Home/End (เมื่อไม่ได้กรอกข้อความหรือโฟกัสปุ่ม)
- โหมดเต็มจอซ่อนเมนูและแถบควบคุม ขยายสไลด์เต็ม 100vw × 100vh ใช้ ←/→ เปลี่ยนหน้า และกด Esc เพื่อออก
- มีภาพรวมสไลด์ หยุด/เล่นภาพซ้ำ เฉลย บันทึกผู้สอน ตัวจับเวลา 5 นาที และ reset ที่มีหน้าต่างยืนยัน
- บันทึกผู้สอนซ่อนไว้เริ่มต้น เมื่อเปิดจะแสดงบนจอเดียวกับผู้ชม ไม่ใช่ presenter view แยกจอ
- WebGL แสดงความสัมพันธ์เชิงแนวคิด หมุน/ซูม/เลือกวัตถุได้ ไม่ใช่ผังหน่วยความจำจริง มี fallback 2D และตัวเลือกสลับ 2D
- แบบตรวจความเข้าใจประจำบทและกิจกรรม Jigsaw จำลองนโยบายการยืมด้วย JavaScript ES6
- ผู้ช่วยเป็น **โหมดสาธิตจากคำตอบที่เตรียมไว้** ไม่มี AI API ไม่มี key และไม่รับคำถามอิสระ
- คำตอบแบบฝึกเก็บใน localStorage key `oop-slides-javascript-v4` ของเบราว์เซอร์นั้น เป็นการฝึกที่ลองใหม่ได้ ไม่ใช่คะแนนทางการ ไม่ส่งถึงผู้สอน และไม่ใช่ leaderboard
- ทุกบทมีลิงก์ไปยังไฟล์โค้ดใน `dist/examples/` และใบงานใน `dist/worksheets/`
- ปุ่มพิมพ์/PDF สร้างหน้าพิมพ์ครบ 88 หน้า ใช้ Print → Save as PDF เฉลยและบันทึกผู้สอนจะรวมเฉพาะเมื่อเปิดปุ่มเหล่านั้นก่อนพิมพ์
- ก่อนใช้สอน ให้เลือกหน้าที่ตรงสัปดาห์ รัน `npm test` ในชุด JavaScript ES6 starter และใช้กิจกรรมปฏิบัติในบทเรียนหลัก
