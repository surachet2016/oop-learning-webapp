# Object Lab — การเขียนโปรแกรมเชิงวัตถุ

เว็บบทเรียนภาษาไทยสำหรับ 07-034-206 ภาคปลาย 2569 ชั้นปี 2 อิง มคอ.3 ฉบับปรับปรุง AI ในโฟลเดอร์แม่

## เปิดในเครื่อง
ต้องมี Node.js จากนั้นเปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```sh
npm start
```

เปิด http://127.0.0.1:4173 หยุดเซิร์ฟเวอร์ด้วย Ctrl+C ไม่มี package ที่ต้องติดตั้งเพิ่ม

## โครงสร้าง
- `dist/index.html` โครงหน้าและเมนู
- `dist/styles.css` การจัดหน้า responsive
- `dist/lessons.js` เนื้อหา 17 สัปดาห์ แก้ไขบทเรียนและแบบทดสอบที่นี่
- `dist/app.js` การแสดงผล ค้นหา แบบทดสอบ ความคืบหน้า และบันทึก AI
- `server.mjs` เซิร์ฟเวอร์พรีวิวเฉพาะเครื่อง

## ขอบเขตการใช้งาน
บทเรียนฉบับเริ่มต้นมีแนวคิด ตัวอย่าง กิจกรรม และคำถามทบทวนหนึ่งข้อต่อสัปดาห์สอน รวม 15 ข้อ สัปดาห์ 8 และ 17 เป็นข้อมูลสอบ ไม่มีข้อสอบจริง การเรียนแล้วเป็นการทำเครื่องหมายเอง ไม่ใช่การรับรองผลสัมฤทธิ์

ไม่มีระบบสมาชิก ฐานข้อมูล การส่งงาน การเก็บคะแนนจริง หรือ AI API ตัวอย่าง Java เป็น snippet เพื่อศึกษา ต้องนำไปประกอบใน Java project; เว็บไม่รัน Java ตัวอย่าง JUnit/JavaFX ต้องตั้งค่า dependencies ตามเครื่องผู้สอนก่อน การกดคัดลอก prompt ไม่ส่งข้อมูลไป AI

บันทึกความคืบหน้าและ AI log ด้วย localStorage เฉพาะ browser+origin เดิม เปลี่ยนพอร์ต/โดเมน/เครื่องจะไม่ย้ายข้อมูลตาม ต้องส่งออกบันทึกไว้เอง ห้ามบันทึกข้อมูลลับ คำตอบแบบทดสอบอยู่ใน source เพราะใช้ฝึกทบทวนเท่านั้น

## Deploy ภายหลัง
เว็บเป็น static HTML/CSS/JS ไม่ต้อง build อัปโหลดเนื้อหาภายใน `dist/` ไปยังพื้นที่เว็บไซต์ที่ผู้ใช้จัดเตรียม รองรับเส้นทางย่อยเพราะใช้ relative assets และ hash routing ไม่มี server secrets และไม่ต้องติดตั้ง Node บน static hosting

ยังไม่ได้เผยแพร่หรือสร้าง hosting ภายนอก ต้องกำหนดโดเมน/พื้นที่ปลายทางในขั้น deploy จริง

## Interactive teaching slides
เปิด `slides.html` จากเมนู “สไลด์การสอน 30 หน้า” ชุดนี้เป็นภาพรวมและแกนหลักของรายวิชา ใช้เลือกประกอบการสอนตามสัปดาห์ ไม่ใช่บทบรรยายเต็มทุกชั่วโมงของ 17 สัปดาห์ ทุกหน้าระบุสัปดาห์และ CLO ตาม มคอ.3

- ซอร์ส: `dist/slides.html`, `slides.css`, `slides-data.js`, `slides-3d.js`, `slides.js`
- ใช้ JavaScript/CSS/WebGL แบบไม่พึ่ง CDN หรือ package ภายนอก เพื่อคงการ deploy แบบ static
- ควบคุมด้วยปุ่มหรือ ←/→, PageUp/PageDown, Home/End (เมื่อไม่ได้กรอกข้อความหรือโฟกัสปุ่ม)
- มีภาพรวมสไลด์ เต็มจอ หยุด/เล่นภาพซ้ำ เฉลย บันทึกผู้สอน ตัวจับเวลา 5 นาที และ reset ที่มีหน้าต่างยืนยัน
- บันทึกผู้สอนซ่อนไว้เริ่มต้น เมื่อเปิดจะแสดงบนจอเดียวกับผู้ชม ไม่ใช่ presenter view แยกจอ
- WebGL แสดงความสัมพันธ์เชิงแนวคิด หมุน/ซูม/เลือกวัตถุได้ ไม่ใช่ผังหน่วยความจำจริง มี fallback 2D และตัวเลือกสลับ 2D
- แบบทดสอบ 5 ข้อ + สถานการณ์ จับคู่ด้วยลากวางหรือ dropdown และจำลองราคา/stock เป็น JavaScript ไม่ใช่ Java runtime
- ผู้ช่วยเป็น **โหมดสาธิตจากคำตอบที่เตรียมไว้** ไม่มี AI API ไม่มี key และไม่รับคำถามอิสระ
- คะแนนและ exit ticket เก็บใน localStorage key `oop-slides-v1` ของเบราว์เซอร์นั้น เป็นการฝึกที่ลองใหม่ได้ ไม่ใช่คะแนนทางการ ไม่ส่งถึงผู้สอน และไม่ใช่ leaderboard
- ปุ่มพิมพ์/PDF สร้างหน้าพิมพ์ครบ 30 หน้า ใช้ Print → Save as PDF เฉลยและบันทึกผู้สอนจะรวมเฉพาะเมื่อเปิดปุ่มเหล่านั้นก่อนพิมพ์ แบบจำลองแสดงเป็นคำอธิบาย 2D ในฉบับพิมพ์
- ก่อนใช้สอน ให้เลือกหน้าที่ตรงสัปดาห์ ตรวจตัวอย่างและทดสอบกับ Java project ของผู้สอน พร้อมใช้กิจกรรมปฏิบัติในบทเรียนหลัก
